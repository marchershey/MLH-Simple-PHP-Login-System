# MLH - Simple PHP Login System

![Demo GIF](https://i.imgur.com/xRI0yeg.gif)

### Current Version: 1.0.2


Created by [Marc Hershey](https://github.com/marchershey)

The MLH Simple PHP Login System is a very lightweight access control application. This project incudes a login form, registration form, and secured page. This was created for my own personal projects, but feel free to use it.

### Installation

Please see my [installation guide]() for help installing.

If you have any questions, comments, or concerns, please create an issue.

### Other Versions

- [Ajax Version]() - Same thing, except this uses Ajax for form submissions.
- [Advanced Version]() - MLH User Management Framework - This is a more in-depth user management system that has way more features.

### Requirements
- Web server software ([Apache](https://httpd.apache.org/), [Nginx](https://www.nginx.com/), [IIS](https://www.iis.net/), etc)
- [MySQL](https://www.mysql.com/) Database
- [PHP 5.6](http://php.net/) or higher

### Dependencies
- [jQuery 3.3.1](https://jquery.com/)
- [Bootstrap 4.1.0](https://getbootstrap.com/)
- [Simple Line Icons 2.4.1](https://github.com/thesabbir/simple-line-icons)

All dependencies are included.
